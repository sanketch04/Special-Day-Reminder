# 🎉 Special Day Reminder System

## 📌 Project Overview

The **Special Day Reminder System** is a web-based application designed to help users manage and remember important events such as birthdays, anniversaries, festivals, meetings, and other personal occasions.

The system provides a user-friendly interface that allows users to add, update, delete, and view important events. It also provides reminder notifications and scheduled email alerts to ensure that users never miss their special occasions.

The application is developed using **Java Spring MVC** for backend development and **MySQL** for database management.

## 🎯 Objectives

- To provide a centralized platform for managing important events.
- To reduce the chances of forgetting birthdays, anniversaries, and other special occasions.
- To provide automatic email notifications and reminders.
- To manage daily schedules through a day planner.
- To provide an easy-to-use and organized interface for users.

## ✨ Features

- **User Management:** Manage user information and access.
- **Event Management:** Add, update, delete, and view important events.
- **Special Day Reminders:** Set reminders for birthdays, anniversaries, festivals, and other occasions.
- **Calendar View:** View and manage events through a calendar.
- **Day Planner:** Organize daily activities and schedules.
- **Email Notifications:** Receive scheduled email reminders for upcoming events.
- **AI Assistance:** Support intelligent assistance for better event management.
